三月份我在公众号上发布了一篇[《你关注的股票值多少钱？DCF估值工具ValueScope更新了》](https://valuescope.app)，介绍了网页版的 AI 一键估值。文章发出去之后，我一直在看后台数据，看到了一个有意思的现象：**用的人很少，但问我"能不能让 Claude 直接帮我算"的朋友，倒是不少。**

想了想，这其实不是功能做得好不好的问题，是形态问题。现在大家有问题都是直接问 AI 的——打开一个网页、找到一个按钮、点一下等结果，这个动作本身已经过时了。

所以这次更新做了一个方向上的调整：**不再让你来网页上用 AI，而是让你自己的 AI 来用 ValueScope。**

## 从"网页上的AI"到"AI里的工具"

这次上线的是 ValueScope 的 **MCP 服务**。MCP（Model Context Protocol）可以理解为 AI 的"通用接口"：一个开放协议，让 Claude、ChatGPT 这些 AI 助手能安全地调用外部工具。你把 ValueScope 接进自己的 AI 之后，AI 就多了一项本事——**用一套标准化的 DCF 引擎给股票算内在价值**。

有朋友可能会问：Claude 本来不就会算 DCF 吗，为什么还需要一个工具？

问得好，这正是我做这个功能前反复想过的问题。AI 确实会"算"DCF，但你让它今天算一次、下个月再算一次，两次的数据来源、报表口径、模型假设可能完全不同——**你分不清估值的变化是基本面变了，还是 AI 这次心情不同。**对于需要长期跟踪几十家公司的人来说，这是致命的。

ValueScope MCP 做的是分工：

- **AI 负责前瞻判断**：搜索最新业绩指引、分析师预期，结合行业逻辑推理每个假设参数——这是 AI 擅长的；
- **引擎负责数据和计算**：A股扣非归母净利润口径、剔除非经营项目的 EBIT 调整、10 年 FCFF 折现、敏感性分析、反向 DCF——这些是引擎的确定性地盘，**同样的输入永远得到同样的结果**。

你的 AI 提供智能，ValueScope 提供纪律。

这个分工还带来一个明显的副产品：**快**。以前让 AI 从头做一次 DCF，它要自己搬财务数据、搭模型框架、逐步推算——相当于让它"心算"一张财务模型，又慢又贵。现在模型框架和数据管道都是现成的确定性代码，单次估值计算在一两秒内完成，历史数据有缓存，换一组假设重算是秒级响应。AI 的时间只花在真正需要智能的地方——判断参数，而不是搬数字和做算术。

## 实际用起来是什么样

接入之后，你在对话里说一句"给贵州茅台做个 DCF 估值"，你的 AI 会自动走完整个流程：

1. 先调用引擎，拿到基于 5 年历史财报的**基线估值**和每个参数的历史区间（比如营收增速过去五年在什么范围、资本效率是升是降）；
2. 按照引擎返回的分析指南，**联网搜索**最新业绩指引和分析师一致预期；
3. 对每个假设参数独立推理、给出依据，再调用引擎算出最终估值；
4. 最后按统一的结构呈现：结论卡、关键假设表（附历史趋势）、价值构成、敏感性区间、反向 DCF——**市场当前价格隐含了什么假设，你是否认同**，还是那个我认为比"目标价"更有价值的逆向思考。

你也可以让它"按乐观、中性、悲观三种情景分别算一遍"，或者"给我看下这几个假设所依据的历史数据趋势图"——引擎会直接返回营收增速、利润率、资本效率的五年趋势图表。

整个过程你只负责提问和判断，数据和计算不需要你操心，也不用担心 AI 编数字——所有财务数据都来自引擎的标准化管道。

## 怎么接入（两分钟）

**Claude Code 用户**（终端和桌面 App 共用同一份配置，命令通用），一行命令：

```
claude mcp add valuescope --transport http https://mcp.valuescope.app/mcp
```

**Claude 网页版 / 手机 App 用户**：设置 → Connectors → 添加自定义连接器，粘贴上面的地址即可。

**Cherry Studio 等桌面客户端**：在 MCP 服务器设置里选 HTTP 类型，填同一个地址。

接入后不需要学任何命令，直接用自然语言提问就行。

## 支持的市场和费用说明

**A股和港股完全免费**，不需要注册任何 API，接入就能用。

**美股和日股**的数据来自 FMP（Financial Modeling Prep）。我用自己的 API 额度提供了**每天 3 次的免费体验**——先体验，觉得有用再注册自己的 key。

注册后把 key 交给 AI 有两种方式，都很简单：

- **对话里直接说**："我的 FMP key 是 xxx，给英伟达估值"——同一个对话里说一次就行，AI 会在每次调用时自动带上；
- **接入时配置一次，永久生效**（推荐）：在接入命令里加一个请求头参数，之后所有对话都不用再提 key：

```
claude mcp add valuescope --transport http https://mcp.valuescope.app/mcp --header "X-FMP-Key: 你的key"
```

体验额度用完时，AI 也会主动告诉你这两种配置方法，照着说的做就行。

## 网页版怎么办

网页版 valuescope.app 还在，而且这次也一起做了升级：个股页加载速度明显变快，每个 Tab 都有了独立链接方便分享。网页版回归它最合适的角色：**手动调参数、看敏感性、快速验证想法的操作台。**如果你喜欢手工调整参数的感觉，网页版仍然是一个很好的 DCF 估值计算器。

但网页上的"AI 一键估值"按钮下线了。原因上面说过——与其我在网页上调一个固定的 AI 替你分析，不如把引擎开放出来，让你用自己顺手的 AI 来分析，它更懂你的上下文，也能追问、能深挖。
