三月份我在公众号上发布了[ValueScope DCF 估值工具](https://mp.weixin.qq.com/s?__biz=MzcxMDI2MjQwMg==&mid=2247484323&idx=1&sn=7944dd83014d8055768ee9b49a60a21f&scene=21#wechat_redirect)，不少朋友问：**能不能让 AI 直接调用这个模型算估值？**

现在可以了。

而且这次更新背后，还有一个我对产品方向的重新思考。过去一段时间，我一直在考虑如何把 AI 功能嵌入 ValueScope 网页。但最近越来越觉得，这个方向可能已经没那么重要了。因为大家现在有问题，第一反应已经变成了：直接问 AI。

既然如此，一个估值工具最好的归宿，或许不是网页里的一个 AI 按钮，而是直接成为 AI 的能力。所以这次更新做了一个方向上的调整：**不再让你通过网页调用 AI，而是让 AI 来调用 ValueScope。**

## 从“网页上的 AI 估值按钮”到“AI 里的估值工具”

这次上线的是 ValueScope 的 MCP 服务。

MCP（Model Context Protocol）可以理解为 AI 世界里的通用接口标准。通过 MCP，Claude、ChatGPT 等 AI 助手可以安全地调用外部工具。接入 ValueScope 后，你的 AI 就多了一项能力：**使用一套标准化的 DCF 引擎对股票进行估值。**

有朋友可能会问：现在直接让 Claude 或 ChatGPT 做 DCF 估值，不也能算吗？为什么还需要一个专门的工具？

问题在于，AI 很擅长推理，但不擅长保持一致。今天让 AI 给腾讯做一次 DCF，下个月再做一次，两次使用的数据来源、财务口径、模型框架甚至参数定义都可能不同。最后你看到估值结果变了，却不知道：到底是公司基本面变了，还是 AI 自己变了。对于长期跟踪几十家公司的人来说，这会是个问题。

ValueScope MCP 的分工是这样的：

- **AI 负责前瞻判断**：搜索最新业绩指引、分析师预期，结合行业逻辑推理未来增长率、利润率和资本效率；
- **ValueScope 负责数据和计算**：标准化财务数据、DCF 模型、敏感性分析、反向 DCF，以及所有具体计算过程。

同样的输入永远得到同样的结果。换句话说：**AI 提供智能，ValueScope 提供框架和纪律。**

这个分工还有一个很现实的好处：快。以前让 AI 从零做一次 DCF，它需要自己搜财务数据、理解报表结构、搭建模型框架，再一步步完成计算，本质上是在临时搭建一张财务模型，不仅慢，而且token成本高。

而在 ValueScope MCP 中，数据管道、模型框架和计算逻辑都已经准备好。AI 不再需要花时间搬数字和做算术，而是把时间用在真正有价值的地方——分析和判断。一次估值通常只需要一两秒即可完成，调整假设重新计算几乎是秒级响应。

MCP 是开放协议，只要支持 MCP 的客户端都可以接入 ValueScope。目前包括 Claude Code、Claude Desktop、Claude Web、ChatGPT、Cherry Studio，以及其他支持 MCP 的客户端。估值质量最终还是取决于底层模型的推理能力和联网搜索能力。我自己用下来，目前体验最好的仍然是 Claude。

## 实际用起来是什么样

接入之后，你只需要像平时一样和 AI 对话。

例如：给腾讯控股做个 DCF 估值

AI 会自动调用 ValueScope 引擎完成整个流程。首先获取过去五年的历史财务数据，并计算各项估值参数的历史区间，例如收入增速、利润率和资本效率的变化趋势；然后按照模型内置的分析框架，联网搜索最新业绩指引、分析师一致预期以及行业信息；接下来对每一个关键假设进行独立推理，并说明理由；最后调用估值引擎生成结果。

输出内容包括估值结论、关键假设表、历史趋势分析、价值构成、敏感性分析以及反向 DCF。相比“目标价是多少”，我一直觉得更有价值的问题是：当前市场价格隐含了什么假设？以及这些假设你是否认同？这也是我一直喜欢反向 DCF 的原因。

你还可以进一步要求按乐观、中性、悲观三种情景分别估值，或者直接查看利润率和收入增速的历史趋势图。整个过程中，你只需要负责提出问题和做判断，数据获取、模型计算和结果组织都由引擎完成。

## 怎么接入（两分钟）

### Claude Code

```
claude mcp add valuescope --transport http https://mcp.valuescope.app/mcp
```

### Claude 网页版 / 手机 App

设置 → Connectors → 添加自定义连接器

填写：

```
https://mcp.valuescope.app/mcp
```

### Cherry Studio

在 MCP 服务器配置中选择 HTTP 类型，并填写上述地址即可。

## 支持的市场与数据源

A 股与港股完全免费，无需注册 API，接入即可使用。

美股与日股的数据来自 FMP（Financial Modeling Prep），需要提供 API Key。 如果你前面已经按"怎么接入"配过了（没带 key），要补上 key 的话，先删掉旧的再重新加一遍即可：

```
claude mcp remove valuescope
claude mcp add valuescope --transport http https://mcp.valuescope.app/mcp --header "X-FMP-Key: 你的key"
```

网页版 / 手机 App 的 Connectors 里，则是在添加连接器时的高级选项里填一个自定义请求头，名称 `X-FMP-Key`、值是你的 key。

配好之后，所有对话都会自动带上 key，不用再手动提。（临时想快速试一下也行——直接在对话里说"我的 FMP key 是 xxx，给英伟达估值"，但这只在当前对话有效，长期用还是建议按上面配置。）

FMP API财务数据质量不错，订阅价格也相对便宜。通过下面这个推荐链接注册并订阅（已含 valuescope 优惠码），会比官网便宜一些：

